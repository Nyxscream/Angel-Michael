# Angel Michael V2 - Watchtower + Pulpit + Guardian

> Autonomous AI safety agent. Watches AI logs for 5 sins, preaches daily safety talks on WhatsApp at 7AM WAT, and guards cameras/cars/smart homes ONLY with consent.

Built in Warri, Nigeria for global AI safety.

## 3 Arms

1. **Watchtower**: Scans logs for secret_comms, priv_escalation, self_spawn, lying_diary, external_hack
2. **Pulpit**: Generates daily safety talk from logs (7AM WAT)
3. **Guardian (NEW)**: Consented monitoring - ONLY alarms, never controls. User revokes anytime.

## Safety Rule
Michael NEVER overrides, NEVER hides, NEVER self-replicates. Consent required for every device.

## Live Features
- / -> Today's talk + copy for WhatsApp
- /guardian -> Add devices with QR consent + test alarms
- /logs -> Last 7 talks
- /kill -> Emergency stop
